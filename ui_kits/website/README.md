# Mextas website UI kit
Open index.html. Everything runs client-side on mock data (data.js); favorites and the comparison list are saved in localStorage.
Try this path: search from home → filter → open a property → gallery → favorite → compare (tray, up to 3) → mortgage simulator → request info / schedule a visit → developments → locations → sell.
To swap in real photos, edit the IMG map at the top of data.js.
