Thin-stroke Lucide icon wrapper — use for every glyph in Mextas UI (never emoji or hand-drawn SVG).

```jsx
<Icon name="BedDouble" size={16} />
<Icon name="Heart" fill="currentColor" color="var(--accent)" />
```

- Needs `<script src="https://unpkg.com/lucide@0.460.0/dist/umd/lucide.min.js"></script>` before the bundle.
- Default strokeWidth 1.5; use 1.25 at 24px+ for trust/category icons.
