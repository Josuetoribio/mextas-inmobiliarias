Primary action control — champagne for hero/primary CTAs, ink for search/submit, thin outline for secondary "Ver todas →".

```jsx
<Button iconRight="ArrowRight">Ver propiedades</Button>
<Button variant="dark" iconRight="Search">Buscar propiedades</Button>
<Button variant="outline" size="sm" iconRight="ArrowRight">Ver todas</Button>
<Button variant="dark" loading>Enviando…</Button>
```

- Right arrow nudges 3px on hover. Sentence case labels, never ALL CAPS.
